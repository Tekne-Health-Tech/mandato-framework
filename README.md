# mandato-framework

Framework aberto para sistemas de mandato parlamentar: configuração por mandato (`tenant.yaml`), motor de temas com verificação de contraste, kit de interface web e mobile, modelo de conteúdo com fluxo editorial e publicação em pacotes estáticos, agenda, perfis com segundo fator e trilha de auditoria, kit de conectores com conectores de dados federais, biblioteca de criptografia e a casca do app do cidadão.

Um mandato sobe só com o framework: conteúdo, agenda e app do cidadão. Módulos adicionais se conectam pelos pontos de extensão publicados.
