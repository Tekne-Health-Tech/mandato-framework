# mandato-framework

Framework da Plataforma de Mandato (Tekne Health Tech): configuração por mandato, tema, kit de UI, conteúdo e publicação, agenda, autenticação e auditoria, kit de conectores, criptografia e casca do app do cidadão.

A licença deste repositório será definida com a decisão da ADR-0012 (proposta: AGPL-3.0 com CLA). Até lá, nenhum código é publicado aqui e todos os direitos são reservados à Tekne Health Tech Ltda.
