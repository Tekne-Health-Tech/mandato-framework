# Contribuindo

1. Abra uma issue antes de um PR grande, para alinharmos o escopo.
2. Todo PR de quem não é da Tekne precisa do [CLA](CLA.md) assinado. O robô do repositório comenta no PR com as instruções; basta responder com a frase indicada.
3. Dependências novas precisam ter licença permissiva (MIT, Apache-2.0, BSD-2/3-Clause, ISC, 0BSD, MPL-2.0). Código sob GPL, LGPL ou AGPL de terceiros não entra. A CI verifica.
4. O framework não importa nada de módulos fechados nem de configuração de mandato. A CI verifica.
5. Nada de segredos, dados pessoais ou dados reais de mandato. Use os dados sintéticos do mandato fictício. A CI procura segredos.
