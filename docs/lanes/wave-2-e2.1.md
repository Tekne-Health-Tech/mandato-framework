# Wave 2 · E2.1: citizen app shell

## What was built

- `apps/mobile`, an Expo Router app with five accessible pt-BR tabs: `inicio`, `mandato`, `causas`, `agenda` and `participe`.
- Build-time tenant loading through `MANDATO_TENANT` (default `tenants/demo`) and `APP_VARIANT`. `citizen` is enabled; `gabinete` fails with `not in E2.1`.
- Tenant name, slug, causes, enabled modules, publication keys and theme come from tenant files. The React Native theme is generated by `packages/core-theme/src/native.js`; code contains no hard-coded colours or remote fonts.
- Offline publication sync backed by `expo-sqlite`: ETag/304 support, Ed25519 manifest verification, sha256 bundle verification, changed-partition downloads, full-snapshot tombstones, takedowns and atomic last-good-state replacement.
- Local demo publication server command: `pnpm --dir apps/mobile serve:published`. Override production source with `MANDATO_PUBLISH_BASE_URL`.
- CI runs mobile tests through `pnpm test`, compiles mobile TypeScript through root `npx tsc -p .`, and exports static web output with telemetry disabled.
